## Git Operations

**CRITICAL: Do NOT commit or push changes without explicit user approval.**

Before any `git commit` or `git push` operation:
1. Show the user what will be committed (use `git diff` or `git status`)
2. Explain the changes clearly
3. Wait for explicit user confirmation before proceeding
4. Only execute the git command after receiving approval

This applies to ALL commits and pushes, regardless of context.
